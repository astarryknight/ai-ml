# Week 8 Final Project Tracks

Each notebook is a **completed reference example**, not a final project to submit unchanged. Students should use the examples to choose a track and learn its workflow, then select a different dataset and adapt the target or output, preprocessing, split, evaluation, and explanation.

1. `track-1-bike-demand.ipynb` — chronological tabular regression
2. `track-2-spotify-recommender.ipynb` — scaled nearest-neighbor recommendations
3. `track-3-sms-spam.ipynb` — SMS spam classification with TF-IDF and an optional RNN comparison
4. `track-4-scene-classifier.ipynb` — image transfer learning with MobileNetV2

All four use the same workflow: frame, acquire, inspect, split, prepare, baseline, model, evaluate, adapt, and share.

Public datasets normally download through Kaggle's `kagglehub` package without authentication. If Kaggle requests authentication in Colab, store the token in Colab Secrets rather than pasting it into a shared notebook.
