# Foundations

Welcome to IEEE AI/ML! This is a beginner-friendly learning library. You can follow the weekly sequence, catch up on a missed session, or study one topic independently.

## What you need

- A browser and a Google account for [Google Colab](https://colab.research.google.com).
- Basic Python variables, conditionals, loops, and functions are helpful but not required before the first lesson.
- Curiosity and willingness to run small experiments.

You do not need local installation or advanced math for the core path. Use [Optional local setup](./local.html) only when you want to work outside Colab.

## A simple way to learn

1. Read a short concept lesson.
2. Run a guided notebook.
3. Use a knowledge check to test your understanding.
4. Make a small visible output such as a plot, table, notebook, or demo.
5. Write one sentence about what you changed or learned.

The [homepage](../../index.html#catch-up-by-week) lists the material by week. You can also browse [Core Concepts](../theory/theory.html), [Resources](../resources.html), [Knowledge Checks](../assessments/checkpoints.html), and [Practice](../minis/minis.html) in any order.

## First lesson

Begin with [What is AI/ML?](./whatisai.html), then continue to [NumPy](./numpy.html). Your Week 1 finish line is a small graph, three short array exercises, and a first song-mood prediction with scikit-learn.
