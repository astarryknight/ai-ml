# Resources

Use this hub when you need a quick definition, a reusable code pattern, or a deeper explanation. The weekly lessons remain the main learning path.

## Course references

- [ML Glossary](./glossary.html) — plain-language definitions with links back to lessons
- [Code Snippets](./code.html) — small examples to copy and adapt
- [Deep Reads](./deep_reads/deep_reads.html) — optional articles that go beyond the core path

## Recommended external resources

Use these after the core lesson when you want a different explanation or more practice. Each resource is labeled by purpose so students know when to open it.

| Resource | Use it when | Level | Type |
| --- | --- | --- | --- |
| [Andrew Ng / DeepLearning.AI Machine Learning Specialization](https://www.deeplearning.ai/specializations/machine-learning) | You want a structured beginner sequence with visual intuition, code, and optional math | Beginner | Core reference |
| [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) | You want short explanations and interactive Colab exercises | Beginner | Core reference |
| [Google MLCC exercises](https://developers.google.com/machine-learning/crash-course/exercises) | You want extra checks, visualizations, and practice notebooks | Beginner | Practice |
| [scikit-learn User Guide](https://scikit-learn.org/stable/user_guide) | You need preprocessing, pipelines, metrics, or model-selection details | Beginner–Intermediate | API reference |
| [fast.ai Practical Deep Learning](https://course.fast.ai/index.html) | You want a practical deep-learning extension with early deployment | Intermediate | Extension course |
| [3Blue1Brown: Gradient Descent](https://www.youtube.com/watch?v=IHZwWFHWa-w) | You want a visual explanation of optimization | Beginner | Optional video |

## Math support

Math is support material, not a gate for the core course.

- [Linear algebra review](https://pillowlab.princeton.edu/teaching/statneuro2024/readings/Eero_geomLinAlg.pdf) - optional reference
- [Intro to PCA](https://github.com/PrincetonUniversity/pni_bootcamp_2023/blob/main/week2/linear_algebra/pca.ipynb) - use alongside the clustering lesson

## Suggested order

1. Complete the weekly lesson and notebook.
2. Use Google MLCC for a second explanation or interactive exercise.
3. Use Andrew Ng's specialization for a deeper structured sequence.
4. Use scikit-learn documentation when implementing or debugging an API.
5. Use fast.ai only after the core path feels comfortable.
